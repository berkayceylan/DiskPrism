# Changelog

## 1.0.0 (2026-11-25)

The first public release.

- Cushion treemap and sunburst of any folder or volume, drawn with Metal, with animated drill-down
- Physical size (what files occupy on this disk) or logical size (how long they are)
- Cloud-only files count 0 bytes on disk, a hard-linked file counts once, and firmlinks are not counted twice
- Directory tree, map and file-type list that stay in sync, with a filter by name or file type
- Reveal in Finder, Quick Look, Copy Path, Open in Terminal, and Move to Trash without a rescan
- Dark and light mode, and no frames drawn while nothing changes
- `--benchmark` and `--snapshot` on the command line
